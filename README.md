# XenForo User Spaces

User Spaces gives XenForo members their own customizable profile landing page with vanity handles (`/@username` and `/u/username`), cover banners, 3 outbound featured links, and a live profile post feed.

## Features
- **100% Native Theme Compatibility**: Zero custom CSS. Uses native XenForo tags and macros so any theme or style works out of the box.
- **Dual Vanity Routing**: Supports both `/@username` and `/u/username`.
- **Custom Branding**: Member-defined title, bio, cover banner, and logo (with forum avatar sync option).
- **3 Outbound Links**: Custom labels, URLs, automatic brand icons, and click tracking.
- **Live Feed**: Native profile posts with quick-post editor and comments.

## Requirements
- XenForo 2.3.0+
- PHP 8.0+
